## Architecture assessment

The existing boundaries are proportionate and should remain:

- Domain holds values and policies without UI imports.
- Application coordinates repository/directory/persistence ports and validates requests.
- Infrastructure implements the live WebSocket/HTTP adapters, mock repository, Keychain, preferences, and bounded disk image cache.
- Composition selects live versus injected development repositories.
- Presentation separates pages, feature composites, leaf components, and observable state.
- NessaDesignSystem owns shared styling and reaction shapes.

No extra target/module hierarchy, generic event bus, global image manager, or speculative cache was introduced. Thumbnail preparation remains off the main actor and occurs once per distinct photo in a message. The native page controller caches at most the group's eight pages, without duplicate sentinel pages. The cache is bounded and scoped by gateway identity. Two-second polling remains the current backend integration strategy; unchanged results no longer invalidate observing screens.

The MCP service remains five small stdio primitives with SQLite persistence, per-agent authorization, bounded uploads, cursor paging, and retry idempotency. Phone transport and actual push notification delivery remain separate future integration work.
